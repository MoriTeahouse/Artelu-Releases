# Artelu · 守林人的回聲

**大更新測試版本・第一版** 的公開遊戲下載與更新發布。

遊戲原始碼保留於私人開發庫；此處只發布可執行成品與公告。

## 下載與開始遊戲

1. 前往 [版本發布頁](https://github.com/MoriTeahouse/Artelu-Releases/releases)。
2. 下載 `Artelu-Launcher-1.0.0-win-x64.zip`，解壓縮到想放置啟動器的位置。
3. 執行 `ArteluLauncher.exe`，選擇安裝硬碟與資料夾，按「下載並安裝」。
4. 安裝完成後按「開始遊戲」。啟動器可自動檢查公開測試版更新，無需 GitHub 登入。

支援 Windows 64 位元；啟動器與遊戲均包含 .NET 執行階段，不需另外安裝 .NET。

## 你的存檔在哪裡？

假設安裝到 `D:\Games\Artelu`，遊戲位於 `Game` 子資料夾，存檔位於 `UserData\Saves`，下載暫存位於 `.launcher`。更新保留存檔。
只有記住安裝位置的小型啟動器設定保存在使用者 AppData。舊版 AppData 存檔會複製到新的安裝位置，不刪除原檔、不覆蓋已有的同名存檔。
